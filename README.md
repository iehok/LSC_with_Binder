# LSC with Binder

## Prepare data
We use the following datasets. 
Please download from these sites. 
Please note that COHA must be purchased directly from the owner. 

Binder features \
https://www.neuro.mcw.edu/index.php/resources/brain-based-semantic-representations/

COHA \
https://www.english-corpora.org/coha/

SemEval 2020 Task 1 \
https://www.ims.uni-stuttgart.de/en/research/resources/corpora/sem-eval-ulscd-eng/

## Set path
After download datasets, please set the path of your environment by editting `src/z_config.py`. 

## Run code
Once the above steps are complete, you will be able to execute the code. 
The code names start with letters like `a_` or `c_`, and are intended to be executed in alphabetical order. 
Note that code with the same initial letter can be executed in any order. 
Additionally, `z_` files contain settings and utilities and do not need to be executed.
